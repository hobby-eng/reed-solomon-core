### Protection and compatibility

The three new equality sites run through the existing ordinary wrapper. Intact/Intact is the only Block variant pair that reads payload bytes. Buffer and Changes reduce the OR of XOR across their entire overlap and reject length mismatch. Plan and Rebuilt delegate to their fields. The formerly unprotected direct comparisons therefore share the documented native cleanup window and callback/ownership exclusions. In strict work the current thread already has a protected stack. After a strict API returns, comparison occurs where invoked by the caller and uses the ordinary policy.

Manual PartialEq introduces a documented source compatibility change for named constants in patterns. Ordinary enum variant patterns remain valid. The downstream compile-only check succeeds on the AUD-009 artifact and returns the expected structural-match diagnostic on the current artifact. The ordinary variant positive control succeeds on the current artifact. The compiler rule is described in the [Rust Reference](https://doc.rust-lang.org/reference/patterns.html#constant-patterns).

The change to Block removes the source-level per-byte early exit for equal-length operands. Branches based on public variant, length and loop position remain. The current Linux x86-64 integration binary (test profile, opt-level 2) uses XOR/OR reductions and a final setcc without a payload-dependent exit in the analyzed loops. This statement is scoped to that binary. Internal duplicate-file comparisons use slice equality under the outer guarded path and retain their short-circuit behavior.

### Findings

#### AUD-010-BLD001 — Low — RustSec CI omits the independent WebAssembly lockfile

- **Status** Open. Release blocker flag is false.
- **Evidence** `.github/workflows/audit.yml:9–21,41–49`, `wasm/Cargo.toml`, `wasm/Cargo.lock`.
- **Expected** Changes to all live dependency lockfiles invoke the advisory check, and the scheduled check covers them all.
- **Observed** The standing workflow only subscribes to the main and fuzz dependency paths and runs two advisory checks. wasm has its own workspace and a third lockfile.
- **Impact** The Wasm graph can drift independently without the standing advisory gate. Its current registry packages match versions and checksums in the main lockfile.
- **Correction** Add the Wasm manifest and lockfile to the triggers and add a third locked advisory check.
- **Verification** Inspect both event filters and all three check inputs. Run the three lockfile audits on the resulting candidate.

#### AUD-010-BLD002 — Low — WebAssembly self-test gate counts passed checks without checking the total

- **Status** Open. Release blocker flag is false.
- **Evidence** `wasm/src/lib.rs:14–20`, `wasm/run.mjs:13–25`, `src/self_test.rs:18–19,27–45`.

- **Correction** Reject self-test recorder overflow, validate the exact number of cases, and require that every case passes.
- **Verification** Check both a fully passing list and a longer list with one failed known answer.
